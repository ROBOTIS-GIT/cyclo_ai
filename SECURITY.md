# Security reporting

Report vulnerabilities privately through this repository's Security tab when private reporting is available. Otherwise contact a repository maintainer to arrange a private channel before sharing sensitive details. Include the affected commit/version, a minimal reproduction, impact and any suggested fix; omit customer credentials and private control tables.

The maintained development branch receives fixes. A stable release support window has not yet been established. Confirm a fix against the current branch rather than assuming an old archive includes it.

The runtime validates device identity, source contracts and write prerequisites. Cooperative bus reservations coordinate plugin processes; they do not lock out unrelated serial applications. Imported tables are local data and do not execute code. These boundaries should remain explicit in security reports and fixes.
